# صندلی خالی

سیستم بصریِ پوستر برای مجموعهٔ **«نشست‌های کتاب‌خوانی، نقد و بررسی آثار نمایشی»**
— کانون نمایشنامه‌نویسان و مترجمان خانه تئاتر.

این یک پوستر تک‌مصرف نیست؛ یک الگوی مادر (Master Template) است. برای هر نشست فقط
متن‌ها عوض می‌شود و تصویر، ترکیب‌بندی و هویت بصری دست‌نخورده باقی می‌ماند.

---

## مفهوم

پرده بالا رفته، ماه پشتِ صحنه است، و روی کتابِ باز فقط یک **صندلیِ خالی** ایستاده:
جای نویسنده‌ای که امشب اثرش خوانده می‌شود. قابِ صحنه، طاقِ کلیلِ ایرانی است —
هم سردرِ معماری، هم دهانهٔ تئاتر.

اجرا به زبانِ **چاپِ دستی** است: کاغذِ کرمِ گرم، چند مرکّبِ محدود، ترامِ نارنجی،
و خطای عمدیِ ثبتِ رنگ (همان جابه‌جاییِ کوچکِ لایه‌ها در چاپ سیلک). تصویر و متن
روی یک تکه‌کاغذِ زرشکیِ **پاره‌شده** چیده شده‌اند، نه داخل کادر و جدول.

## پالت

| نقش | رنگ | کد |
|---|---|---|
| کاغذ — زمینه | کرمِ گرم | `#F2E7D0` |
| پرده و تأکیدِ بلند | زرشکیِ گرم | `#A31E2F` |
| شبِ صحنه و همهٔ متن | آبیِ کبالت | `#17306B` |
| ماه | کرمِ طلایی | `#EFDCA8` |
| تأکیدِ آرام (برچسب‌ها) | فیروزهٔ ایرانی | `#1B9299` |
| ترامِ چاپ و خطای ثبت | نارنجیِ ایرانی | `#DE7429` |

پوستر تیره نیست: زمینه کاغذِ روشن است و زرشکی و فیروزه‌ای کارِ جلبِ نگاه در فید
را انجام می‌دهند.

## تایپوگرافی

| نقش | قلم |
|---|---|
| عنوان نشست و تاریخ | **Lalezar** — حروفِ پوستریِ ایرانی |
| نام آثار (صدای ادبی) | **Markazi Text** ۷۰۰ |
| نام‌ها، برچسب‌ها، اطلاعات | **Vazirmatn** ۴۰۰/۵۰۰/۶۰۰/۷۰۰ |

عنوان در **دو تکه** بسته می‌شود: واژه‌ها به رنگِ کبالت، و یک تکهٔ درشتِ زرشکی
(اینجا «۱۴۰۵») با اختلافِ اندازهٔ زیاد کنارش. هر سه قلم متن‌بازند (SIL OFL) و
به‌صورت `woff2` کنار الگو قرار دارند؛ پوستر به هیچ فونتِ نصب‌شده‌ای وابسته نیست.

## سلسله‌مراتب

۱. تصویر و عنوان (بالا، با هم) — ۲. عنوان اثر و نویسنده روی تکه‌کاغذ —
۳. منتقدان، مجری، مهمان ویژه — ۴. تاریخ و ساعت و مکان — ۵. لوگوها.

## ویرایش برای نشستِ بعدی

همهٔ متن‌ها در یک شیء در بالای `poster.html` است. فقط همان را عوض کنید:

```js
const DATA = {
  title:  'نقد و بررسی کتاب',   // واژه‌ها — کبالت
  accent: '۱۴۰۵',               // تکهٔ درشتِ زرشکی؛ خالی بماند، عنوان تمامِ عرض را می‌گیرد

  books:  ['[عنوان کتاب اول]', '[عنوان کتاب دوم]'],   // یک یا چند عنوان
  author: 'نوشته [نام نویسنده / نویسندگان]',

  rows: [
    { label: 'با حضور و نقد',    names: ['[منتقد اول]', '[منتقد دوم]'] },
    { label: 'رئیس جلسه / مجری', names: ['[نام مجری]'] },
    { label: 'مهمان ویژه',       names: ['[نام مهمان]'] },   // ← کلِ گروه حذف‌شدنی است
  ],

  date: 'پنجشنبه ۲۹ مرداد ۱۴۰۵',
  time: '۱۷:۰۰',
  venue:'سالن مشاهیر تئاتر شهر تهران',
  address:'[آدرس کامل محل برگزاری]',
  entry:'ورود برای عموم آزاد است',   // اختیاری
};
```

قاعده‌های سیستم:

- **طولِ عنوان مهم نیست.** اندازهٔ حروف با شمارشِ واقعیِ سطرها محاسبه می‌شود؛
  از «شبِ بیضایی» تا عنوانی هفت‌کلمه‌ای، هر دو کادر را پُر می‌کنند.
- **حذف = خالی گذاشتن.** گروهی که `names` نداشته باشد یا مقداری که `''` باشد،
  کامل کنار می‌رود و جای خالی‌اش بسته می‌شود. با حذفِ گروهِ دوم، بخشِ اهالی
  خودبه‌خود یک‌ستونی می‌شود.
- **تعداد آزاد است.** یک یا دو کتاب، یک تا چند منتقد، سه تا پنج لوگو.
- **شبکهٔ ایمنی.** اگر متنِ یک نشست غیرعادی بلند شد، ستونِ متن به‌جای شکستن،
  تا ۲۲٪ جمع می‌شود و نسبت‌ها حفظ می‌ماند.

### جای‌گذاریِ لوگوها

پاورقی یک ردیفِ هویتی است، نه چند مستطیل. هر لوگو با نامِ متنی جای‌نگه‌داری شده؛
برای گذاشتنِ فایل، محتوای `.logo` را با تصویر عوض کنید:

```html
<span class="logo"><img src="./logos/khaneh-teatr.svg" alt="خانه تئاتر"></span>
```

ارتفاعِ لوگوها در CSS ثابت است (`.logo img{height:calc(46 * var(--u))}`) تا ردیف
یک‌دست بماند. لوگوهای `required:false` («در صورت تأیید») کم‌رنگ‌ترند و حذفشان
هیچ اثری روی بقیهٔ ردیف ندارد.

## خروجی گرفتن

```bash
npm i playwright          # فقط بارِ اول
node build.js                                  # با اطلاعاتِ پیش‌فرض
node build.js sessions/mordad.json --name mordad-29    # با اطلاعاتِ یک نشست
```

| فایل | اندازه | کاربرد |
|---|---|---|
| `out/*-post.png` | ۱۰۸۰×۱۳۵۰ | پستِ اینستاگرام، تلگرام، واتساپ |
| `out/*-story.png` | ۱۰۸۰×۱۹۲۰ | استوری — با رعایت حاشیهٔ امنِ بالا و پایین |
| `out/*-print.png` | ۳۵۷۸×۵۰۳۱ | A3، ۳۰۰dpi، با ۳ میلی‌متر نشتِ رنگ |
| `out/*-print.pdf` | ۳۰۳×۴۲۶ mm | فایلِ چاپخانه؛ متن برداری، با علامتِ برش |

فایل `sessions/*.json` فقط همان کلیدهای `DATA` را بازنویسی می‌کند — نمونه در
`sessions/example.json`.

بدون Node هم می‌شود کار کرد: `poster.html` را در مرورگر باز کنید
(`?f=post` / `?f=story` / `?f=print`)، متن‌ها را ویرایش کنید و با
Print → Save as PDF خروجی بگیرید.

## سه جهت‌گیریِ هنری

سه پیشنهادِ بصری روی همان یک ساختار و همان شیء `DATA` ساخته شده‌اند:

| فایل | جهت | زبانِ بصری |
|---|---|---|
| `poster.html` | **الف · صندلی خالی** | تصویرسازیِ روایی، طاقِ ایرانی، چاپِ دستی |
| `poster-b.html` | **ب · سیاه‌مشق** | تایپوگرافیِ محض، نستعلیق، صفحهٔ نسخهٔ خطی |
| `poster-c.html` | **ج · کتیبه** | مینیمالِ گالری، پلانِ رنگیِ تخت، کاشیِ گرهِ هشت‌پر |

```bash
node build.js                                # جهتِ الف
node build.js --page poster-b.html --name b  # جهتِ ب
node build.js --page poster-c.html --name c  # جهتِ ج
```

انتخابِ جهت، انتخابِ ظاهر است نه روشِ کار: قواعدِ انعطاف، اندازهٔ خودکارِ عنوان،
حذفِ بخش‌های اختیاری و چهار خروجی در هر سه یکسان است.

## فایل‌ها

```
poster.html              جهتِ الف — صندلی خالی
poster-b.html            جهتِ ب — سیاه‌مشق
poster-c.html            جهتِ ج — کتیبه
poster.standalone.html   همان الگو با فونت‌های جاسازی‌شده (یک فایل، بدون وابستگی)
build.js                 ساختِ چهار خروجی از روی الگو
fonts/                   Lalezar · Markazi Text · Vazirmatn · Gulzar (SIL OFL)
sessions/example.json    نمونهٔ اطلاعاتِ یک نشست
out/                     خروجی‌ها
```

## چاپ

تصویر تمامش برداری است؛ در هر اندازه‌ای تیز می‌ماند. رنگ‌ها RGB هستند: برای چاپِ
افست فایل PDF را به CMYK تبدیل کنید و زرشکی و فیروزه‌ای را با چاپخانه چک کنید
(هر دو در CMYK کمی کدرتر می‌افتند). برای چاپِ دیجیتال، همان PDF کافی است.
