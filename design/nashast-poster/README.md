# صحنه و صفحه

سیستم بصریِ پوستر برای مجموعهٔ **«نشست‌های کتاب‌خوانی، نقد و بررسی آثار نمایشی»**
— کانون نمایشنامه‌نویسان و مترجمان خانه تئاتر.

این یک پوستر تک‌مصرف نیست؛ یک الگوی مادر (Master Template) است. برای هر نشست فقط
متن‌ها عوض می‌شود و چیدمان، سلسله‌مراتب و هویت بصری دست‌نخورده باقی می‌ماند.

---

## مفهوم

طاقِ انتزاعیِ ایرانی که هم‌زمان **قابِ صحنهٔ تئاتر** است، و صفحهٔ کاغذِ کرم‌رنگی که
**اثرِ ادبی** را در دلِ آن قاب می‌نشاند. هندسه از کاشی‌کاری و شمسه گرفته شده، اما
به‌جای تزئین، نقشِ ساختاری دارد: خطِ مویی، بریده با لبهٔ کادر، پشتِ تایپوگرافی.

## پالت

| نقش | رنگ | کد |
|---|---|---|
| زمینه | لاجوردی عمیق | `#12233F` → `#0A1526` |
| کاغذ و متن | کرم استخوانی | `#F2EBDD` |
| نشانه‌ها و خطوط | طلایی مات | `#C9A46A` |
| تنها نقطهٔ تأکید | زرشکی | `#7E1F2E` |
| فقط داخل نقشِ هندسی | فیروزه‌ای تیره | `#1B5E63` |

هر پنج رنگ هم‌زمان و هم‌وزن استفاده نمی‌شوند: لاجورد و کرم بدنهٔ کار را می‌سازند،
طلایی فقط برچسب‌ها و خطوط است، و زرشکی تنها یک‌بار — روی نوارِ زمان و مکان.

## تایپوگرافی

| نقش | قلم | وزن |
|---|---|---|
| عنوان اصلی، نام‌ها، اطلاعات | **Vazirmatn** | ۹۰۰ / ۷۰۰ / ۵۰۰ / ۴۰۰ |
| نام آثار (صدای ادبی) | **Markazi Text** | ۷۰۰ |
| امضای کنارهٔ پوستر | Vazirmatn لاتین | ۵۰۰ |

هر دو قلم متن‌بازند (SIL OFL) و به‌صورت `woff2` در `fonts/` کنار الگو قرار دارند؛
پوستر به هیچ فونتِ نصب‌شده روی سیستم وابسته نیست.

## سلسله‌مراتب

چشم به این ترتیب هدایت می‌شود:

1. عنوان نشست — درشت‌ترین عنصر، تا دو سطر
2. عنوان اثر / آثار — روی صفحهٔ کاغذ، با قلمِ ادبی
3. نویسنده
4. منتقدان، مجری، مهمان ویژه — جدولِ برچسب/نام
5. تاریخ، ساعت، مکان — نوارِ زرشکی
6. آدرس و لوگوها — پاورقی، بدون رقابت با عنوان

## ویرایش برای نشستِ بعدی

همهٔ متن‌ها در یک شیء در بالای `poster.html` است. فقط همان را عوض کنید:

```js
const DATA = {
  title:  'نقد و بررسی کتاب <em>۱۴۰۵</em>',   // هرچه داخل <em> باشد طلایی می‌شود
  books:  ['[عنوان کتاب اول]', '[عنوان کتاب دوم]'],   // یک یا چند عنوان
  author: 'نوشته [نام نویسنده / نویسندگان]',
  rows: [
    { label: 'با حضور و نقد',    names: ['[منتقد اول]', '[منتقد دوم]'] },
    { label: 'رئیس جلسه / مجری', names: ['[نام مجری]'] },
    { label: 'مهمان ویژه',       names: ['[نام مهمان]'] },   // ← کلِ سطر حذف‌شدنی است
  ],
  when: [ { label:'تاریخ', value:'…' }, { label:'ساعت', value:'…' },
          { label:'مکان', value:'…' } ],
  ...
};
```

قاعده‌های سیستم:

- **طولِ عنوان مهم نیست.** اندازهٔ حروف خودکار محاسبه می‌شود تا حداکثر دو سطر پُر شود.
- **حذف = خالی گذاشتن.** سطری که `names` نداشته باشد، یا مقداری که `''` باشد،
  کامل کنار می‌رود و جای خالی‌اش بسته می‌شود؛ چیدمان به‌هم نمی‌ریزد.
- **تعداد آزاد است.** یک یا دو کتاب، یک تا چند منتقد، سه تا پنج لوگو.
- **شبکهٔ ایمنی.** اگر متنِ یک نشست غیرعادی بلند شد، ستونِ محتوا به‌جای شکستن،
  کمی جمع می‌شود (حداکثر ۱۸٪) و نسبت‌ها حفظ می‌شود.

### جای‌گذاریِ لوگوها

قاب‌های پاورقی جای‌نگه‌دار هستند. برای هر لوگو، محتوای `.slot` را با تصویر عوض کنید:

```html
<div class="slot"><img src="./logos/khaneh-teatr.svg" alt="خانه تئاتر"></div>
```

```css
.slot img{max-width:100%;max-height:calc(48 * var(--u));
          filter:brightness(0) invert(1) opacity(.82)}   /* یک‌دست‌سازی روی لاجورد */
```

قاب‌های خط‌چین یعنی «در صورت تأیید»؛ با `required:false` مشخص می‌شوند و حذفشان
هیچ اثری روی بقیهٔ نوار ندارد.

## خروجی گرفتن

```bash
npm i playwright          # فقط بارِ اول
node build.js                                  # با اطلاعاتِ پیش‌فرض
node build.js sessions/mordad.json --name mordad-29    # با اطلاعاتِ یک نشست
```

| فایل | اندازه | کاربرد |
|---|---|---|
| `out/*-post.png` | ۱۰۸۰×۱۳۵۰ | پستِ اینستاگرام، تلگرام، واتساپ |
| `out/*-story.png` | ۱۰۸۰×۱۹۲۰ | استوری — با رعایت حاشیهٔ امنِ بالا و پایین |
| `out/*-print.png` | ۳۵۷۹×۵۰۳۲ | A3، ۳۰۰dpi، با ۳ میلی‌متر نشتِ رنگ |
| `out/*-print.pdf` | ۳۰۳×۴۲۶ mm | فایلِ چاپخانه؛ متن برداری، با علامتِ برش |

فایل `sessions/*.json` فقط همان کلیدهای `DATA` را بازنویسی می‌کند — نمونه در
`sessions/example.json`.

بدون Node هم می‌شود کار کرد: `poster.html` را در مرورگر باز کنید
(`?f=post` / `?f=story` / `?f=print`)، متن‌ها را ویرایش کنید و با
Print → Save as PDF خروجی بگیرید.

## فایل‌ها

```
poster.html              الگوی مادر — طراحی و متن‌ها
poster.standalone.html   همان الگو با فونت‌های جاسازی‌شده (یک فایل، بدون وابستگی)
build.js                 ساختِ چهار خروجی از روی الگو
fonts/                   Vazirmatn و Markazi Text (SIL OFL)
sessions/example.json    نمونهٔ اطلاعاتِ یک نشست
out/                     خروجی‌ها
```

## چاپ

رنگ‌ها RGB هستند. برای چاپِ افست، فایل PDF را به CMYK تبدیل کنید و لاجورد را
با چاپخانه چک کنید (لاجوردِ عمیق در CMYK کمی تیره‌تر می‌افتد؛ در صورت نیاز
`--lapis` را یک پله روشن‌تر بگیرید). برای چاپِ دیجیتال، همان PDF کافی است.
