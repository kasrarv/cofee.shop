# فریمور — تغییرات ESP32-DIV

پچ اصلی: **`esp32-div-mods.patch`** (شامل هر دو مورد زیر). اعمال روی مخزن اصلی:
```bash
git clone https://github.com/cifertech/ESP32-DIV.git && cd ESP32-DIV
git apply /path/to/esp32-div-mods.patch
```
تست شده که تمیز apply می‌شود. حتماً در Arduino IDE یک‌بار Verify/Compile بگیر
(در این محیط امکان کامپایل سخت‌افزاری نبود).

این پچ دو چیز اضافه می‌کند:
1. گزینه‌ی **`Read & Write`** در منوی RFID (کلون سریع UID).
2. گزینه‌ی **`Radar`** در منوی Other (نمایش حضور/ضربان/تنفس/خواب از C1001).
   > برای رادار کتابخانه‌ی **`DFRobot_HumanDetection`** را نصب کن و پین‌های
   > `RADAR_RX/RADAR_TX` را در `radar.cpp` روی دو GPIO آزاد بگذار.

اسکچ‌های مستقل قابل‌تست هم هست: `radar_c1001/` (رادار) و `pn5180_reader/` (PN5180).
جزئیات ارتقای PN5180 در `radar-integration.md`.

## گزینه‌ی «Read & Write»

یک فلوی سریع سه‌مرحله‌ای برای **کلون UID فوب/کارت** روی کارت خام Gen2 «magic»
(کاربرد رایج: کپی کارت اکسس آپارتمان).

مرحله‌ها:
1. کارت **مبدأ** را آهسته و نزدیک از روی کویل رد کن (زیر ~۳ سانت). UID خوانده می‌شود.
2. کارت مبدأ را بردار.
3. کارت **خام magic** را بگذار → UID به‌طور خودکار نوشته می‌شود. با `Card Reader` تأیید کن.

> برای کپی کامل حافظه‌ی تگ‌های Ultralight/NTAG از همان گزینه‌ی موجود **`Card Clone`**
> استفاده کن. گزینه‌ی جدید فقط برای کلون سریع UID روی MIFARE Classic magic است.

### چرا فقط برد کوتاه؟
همان کویل ۱۳.۵۶ مگاهرتزی PN532 استفاده می‌شود؛ برد واقعی ~۲–۵ سانت است. «Swipe»
یعنی پاس آهسته و نزدیک، نه خواندن از ۱۰–۲۰ سانت (که در این فرکانس ممکن نیست).

## تغییرات فنی (۳ فایل)

| فایل | تغییر |
|---|---|
| `ESP32-DIV/rfid.h` | اعلان `void sessionReadWrite();` |
| `ESP32-DIV/rfid.cpp` | پیاده‌سازی `sessionReadWrite()` (فقط با هلپرهای موجود و اثبات‌شده) |
| `ESP32-DIV/ESP32-DIV.ino` | افزودن آیتم منو، آیکون، و `case 8` در dispatch |

کد جدید فقط از توابع موجود پروژه (`rfidListenIso14443a`, `detectCardType`,
`tryMagicBackdoor`, `mifareclassic_*`, `rfidResultAndDismiss`, ...) استفاده می‌کند تا
ریسک کامپایل کم باشد. **قابلیت‌های قبلی دست‌نخورده‌اند** (فقط اضافه شده).

سپس در Arduino IDE:
- برد: **ESP32S3 Dev Module**
- کتابخانه‌ها طبق پوشه‌ی `Libraries` مخزن + **Adafruit PN532**
- `BoardConfig.h` روی `BOARD_ESP32_DIV_V2` (پیش‌فرض) بماند
- کامپایل و فلش

> ⚠️ چون در این محیط امکان کامپایل سخت‌افزاری نبود، حتماً یک‌بار Verify/Compile بگیر.
> کد از الگوهای موجود کپی شده ولی تست روی سخت‌افزار به عهده‌ی توست.
