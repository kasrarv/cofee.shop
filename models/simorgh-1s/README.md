# SIMORGH-1S — هواپیمای مدل پرینت‌سه‌بعدی، تک‌سل (1S)

هواپیمای بال‌بالا، ۳ کاناله (گاز / سکان / ارتفاع)، طراحی‌شده برای یک باتری
لیتیومی تک‌سلی و یک موتور براشلس کوچک. تمام قطعات زیر ۲۵۰ میلی‌متر هستند و
بدنه از چهار بخش جداشدنی ساخته می‌شود.

| | |
|---|---|
| دهانه بال | ۸۵۰ mm |
| طول کل | ۷۸۶ mm |
| سطح بال | ۱۱٫۹۴ dm² |
| نسبت منظری | ۶٫۰۵ |
| ایرفویل | Clark Y (کف صاف) |
| زاویه نصب بال | ‎+۲°‎ |
| دایهدرال | ۱۰° روی پنل بیرونی (پلی‌هدرال) |
| وزن اسکلت چاپ‌شده | ۱۸۴ g با LW-PLA |
| وزن پروازی | ‎~۳۴۰ g‎ |
| بارگذاری بال | ۲۸٫۵ g/dm² |
| سرعت واماندگی | ۶٫۳ m/s (۲۳ km/h) |
| **مرکز ثقل** | **۴۰ mm پشت لبه حمله بال** (۲۸٪ MAC) |

## فایل‌ها

```
stl/                 ۱۵ فایل STL، هرکدام در جهت صحیح چاپ
geom.py              کتابخانه هندسه (لافت پوسته نازک، ایرفویل، آفست)
airframe.py          ژنراتور پارامتریک تمام قطعات
performance.py       تحلیل موتور/ملخ/باتری و بودجه وزن
render.py            رندر نرم‌افزاری برای بازبینی
preview_*.png        نماهای مدل
```

بازتولید مدل با پارامترهای دلخواه:

```bash
pip install numpy scipy shapely trimesh manifold3d networkx
python3 airframe.py          # -> stl/
python3 performance.py       # جدول موتور و وزن
```

پارامترهای مهم بالای `airframe.py` هستند: `SERVO_L/W/H` (جای سروو)،
`C_ROOT/C_MID/C_TIP` و `B_INNER/B_OUTER` (پلان بال)، `SPAR_D` (قطر میله کربن)،
و `SKIN` در `geom.py` (ضخامت پوسته).

## نکته مهندسی: چرا یک موتور، نه دو تا

با ۳٫۷ ولت، توان در دسترس به شدت محدود است. `performance.py` نقطه کار واقعی
موتور و ملخ را حل می‌کند (نه فقط تخمین تکانه‌ای):

| موتور | ملخ | دور | جریان | رانش | T/W |
|---|---|---|---|---|---|
| 2204 2300KV | 6×4 | ۷۳۰۶ | ۳٫۳ A | ۱۰۰ g | ۰٫۲۹ ✗ |
| 2204 2300KV | 7×4 | ۶۵۷۱ | ۵٫۱ A | ۱۴۷ g | ۰٫۴۳ |
| **2205 3000KV** | **6×3** | **۸۹۹۰** | **۵٫۲ A** | **۱۶۳ g** | **۰٫۴۸ ✓** |
| 2306 3600KV | 6×4 | ۹۶۴۸ | ۸٫۲ A | ۱۷۴ g | ۰٫۵۱ (بیش از حد سل ۳۵E) |
| 2×1105 5000KV | 4×4 | — | ۷٫۵ A | ۱۶۷ g | ۰٫۴۹ |

نتیجه: در ولتاژ پایین، **ملخ بزرگ‌تر با KV بالا** بهترین بازده را می‌دهد.
دو موتور کوچک تقریباً همان رانش را با پیچیدگی و وزن بیشتر می‌دهند، پس بدنه
برای تک‌موتور طراحی شده است.

## هشدارهای خرید

1. **ESC باید صراحتاً 1S باشد.** بیشتر ESCهای BLHeli_S حداقل ۲S هستند.
2. **مبدل افزاینده ۵ ولت (۲ آمپر) لازم است** — سروو و ESP32 با ۳٫۷ ولت درست
   کار نمی‌کنند.
3. **۳۵۰۰ mAh در ۴۰ گرم از نظر فیزیکی ممکن نیست** (~۳۲۴ Wh/kg). سل واقعی
   ۳۵۰۰ mAh حدود ۴۵–۶۵ گرم است. جای باتری برای پاکت تا ۱۱۰×۴۰×۲۰ mm طراحی
   شده و همان جا ابزار تنظیم مرکز ثقل است.

## چاپ

- متریال: **LW-PLA** (فوم‌شونده). چگالی مؤثر ~۰٫۵۸ g/cm³.
- نازل ۰٫۴، **یک پریمتر با عرض خط ۰٫۴۵** (پوسته دقیقاً ۰٫۴۵ mm مدل شده)
- ارتفاع لایه ۰٫۲ mm (قطعات جفت‌شونده) تا ۰٫۲۵ mm (پوسته‌ها)
- **اینفیل ۰٪**، لایه بالا/پایین ۲، بدون ساپورت
- جهت چاپ داخل خود فایل‌ها اعمال شده — قطعات را نچرخانید.

جزئیات کامل مونتاژ و سیم‌کشی در دفترچه ساخت (artifact) آمده است.
